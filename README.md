# Start-Screen-Win8-New-Tab-for-Edge
Start Screen · Win8 New Tab for Edge

Start Screen · Win8 New Tab turns your new tab page into a Windows 8 style Start screen: a grid of large, colourful tiles, each showing the real icon of the site it opens, sliding in with a smooth entrance animation.

## FEATURES
- Real site icons. Every tile shows the actual favicon of the website, loaded through the browser's favicon API and cached locally. If a site has no icon, a globe placeholder is drawn instead, so a tile never looks broken.
- A grid that fits your screen. Tiles are laid out in six columns and sized from the window height, so the same layout fills a laptop screen and a large monitor without scrolling.
- Drag to reorder. Press and hold any tile to lift it, then drop it where you want it. The tiles around it slide into their new places with an animation, so you always see where it will land.
- Three tile sizes. Small (one column), wide (two columns) and double (two columns, two rows). Change the size from the tile's edit dialog and the grid re-flows around it.
- Edit and delete. Right-click a tile, or click the pencil button in edit mode, to open one dialog where you can rename the site, change its URL, pick a colour from six Metro palettes, or change its size. The × button removes a tile with an exit animation.
- Add a site. A dashed "add" block sits at the end of the grid; click it to type a name and a URL. You can also pick an existing URL straight from your bookmarks or from pages you visited in the last 90 days, instead of typing it.
- Search from the top bar. Type in the search box and press Enter to search with Bing, which is matched to your interface language; the magnifier button focuses the box when it is empty.
- Custom backgrounds. Six built-in gradient presets, or your own image from disk — it is downscaled to 1920 px and stored locally — plus an overlay slider so tile text stays readable on bright photos.
- Eight languages. English, 简体中文，繁體中文，日本語，한국어, Deutsch, Français and Español. The whole interface, the default tiles and the default search engine are matched to the language, and you can switch language any time with the globe button in the top bar.

## PRIVACY
Everything stays on your device. There is no account, no sync server, no analytics, no advertising and no remote code — the whole extension is contained in the package and works with the network disconnected. Your tile list, background choice and language preference are stored locally. Bookmarks and history are read only at the moment you open the "pick from bookmarks / history" dialog, and the list is discarded when it closes. Nothing is sent to the developer or to any third party.
