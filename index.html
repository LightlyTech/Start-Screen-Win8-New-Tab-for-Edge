它的作用

以下内容均为1.6.5版本。这些都不会改变其他网站，不会改变搜索结果，也不需要服务器。

  • 真实网站图标

    每个瓦片通过浏览器的 favicon API 拉取网站的图标。没有地球仪的网站会看到地球仪，从来没有坏掉的图片。

  • 一个合适的网格

    每个屏幕有六列，单元格大小根据窗口高度计算，所以笔记本电脑和大显示器都能填满而不滚动。

  • 拖拽换单

    按住任意一块，放到你想要的位置;中间的格子会滑过，这样你就能看到落点，然后松开。

  • 三种瓷砖尺寸

    小号、宽号或双倍高度。在瓦片对话框中选择一个，网格会围绕新的封装重新流动。

  • 一个对话框编辑

    右键点击瓦片——或使用顶部栏的铅笔——更改其名称、网址、颜色（六个调色板）或大小。

  • 用出口删除

    ×先淡出一格，然后再填补后方的空隙。恢复默认设置会恢复原来的十六个。

  • 从书签中选择

    添加对话框可以列出你的书签，或者你过去90天内访问过的页面，并选择其中一个，而不是输入的URL。

  • 从顶部栏搜索

    输入并按回车键搜索 Bing，匹配你的界面语言。放大镜只是在视场空时聚焦。

  • 自定义背景

    六个渐变预设，或者你自己的照片缩放到1920像素并保存在机器上，再加上一个暗滑块，确保磁片名称清晰可见。

  • 八种语言

    界面、默认磁贴和搜索引擎都遵循你的语言——随时从地球仪按钮切换。

隐私政策

该政策涵盖了 Microsoft Edge 扩展“开始屏幕·Win8 新标签页“，版本 1.6.5。

最后更新：2026年11月11日

简短版

扩展所知道的所有信息都保存在你自己的设备上。它没有账户系统，没有服务器，没有分析数据，没有广告，也没有远程代码。你在里面做的任何事情都不会被发送给开发者或其他人。

你设备上存储了什么

扩展保存了三样东西，让页面下次看起来一样：

  • 你的图块列表：每个添加或更改的瓦片的名称、URL、颜色、大小和位置。
  • 你的背景：一个命名的预设渐变，或者你选的图片（放大到最多1920像素），加上它的暗度。
  • 你的接口语言。

这些是 ，作为备选方案。拆除延长部分会移除它们;没有任何副本会被保存在其他地方。chrome.storage.locallocalStorage

你要读什么，而且只有你主动要求时才会读

有两个权限纯粹是填写URL而不输入。两者仅在屏幕上“选择网站”对话框打开时使用：

  • 书签——切换到书签标签页时请通读一遍，这样你可以选择保存的页面。文件夹树在内存中被压扁;不会创建、更改或删除任何书签。chrome.bookmarks.getTree()
  • 历史——切换到历史标签页时，请通读一遍，限于最近90天。结果列表会保留在页面内存中，对话框关闭时会被丢弃。chrome.history.search()

这两个列表都不会被存储、记录或传输。如果你从未打开那个对话框，任何许可都不会被行使。

网络活动

扩展本身没有任何请求：没有更新ping，没有遥测端点，没有字体或资源下载。网站图标通过浏览器自己的收藏区商店通过权限获取。当你打开一个磁贴，或在搜索栏按回车时，浏览器会像从地址栏加载那样加载该页面。favicon

权限以及每个权限的用途

许可为什么被要求
storage这样可以把你的瓦片、背景和语言都保存在设备上。没有它，每个新标签页都得从头开始。
favicon在每个网站的图块上绘制真实图标。只有你添加的URL图标会被请求。
bookmarks它允许你选择保存页面，而不是输入它的URL，同时添加对话框还在开启。
history你可以在对话框打开时选择最近访问过的页面。

它从未做到的

  • 不得收集、销售、分享或转移个人数据给任何人。
  • 没有分析、事故报告、广告或任何形式的追踪。
  • 无远程代码：所有代码均附带在包裹内，符合本商店的Manifest V3规则要求。
  • 禁止内容脚本：你访问的任何页面都不会被阅读、修改或注入。
  • 不能访问密码、表单数据、其他扩展，或者超过上述四个权限的任何权限。
